🤖 AI 공고 분석 & 답변 창

좌측 목록에서 공고의 [🤖 AI 질문]을 누르거나 질문을 입력하시면 이 공간에 상세 답변이 표시됩니다.
💡 사용 팁: 1. 각 공고의 [📄 개요 ▼] 또는 [🤖 AI 질문]을 누르세요. 2. 추천 질문 버튼을 클릭하거나 궁금한 내용을 질문하면, 이곳 우측 패널에 AI의 분석 답변이 넓고 보기 편하게 표시됩니다. 3. 공고 아래(기존 답변 자리)에는 내가 질문했던 기록이 차곡차곡 누적되며, 기록을 클릭하면 언제든 다시 답변을 볼 수 있습니다!

🤖 AI 질문하기 (Google Gemini API 키 설정)

무료 Google Gemini API 키를 1회 등록해 두시면, 각 공고에서 질문할 때마다 우측 전용 패널에 2~3초 만에 즉시 답변이 표시되고 질문 기록이 누적 저장됩니다!

👉 Google AI Studio에서 무료 API 키 발급받기 (Create API key 클릭)

🔑 GitHub 서버 동기화 토큰 설정

웹에서 삭제한 공고, 추가한 키워드 및 검색 사이트를 GitHub 서버 파일(data.json, config.json)에 직접 저장하려면 GitHub Personal Access Token(Classic repo 권한)을 1회 입력해 주세요.

👉 여기를 눌러 GitHub 토큰 10초 만에 발급받기 (하단 Generate token 클릭)
